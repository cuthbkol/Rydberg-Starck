# Rydberg Starck Website

Static website source for Rydberg Starck Limited.

## Develop locally

Install Node.js, run `npm install`, and start the Tailwind watcher with `npm run watch`. Open `index.html` with Live Server to preview changes. Run `npm run build` before publishing to rebuild the compiled stylesheet.

The website is published from the `main` branch using GitHub Pages. Pages are built into a clean `_site` folder so development files and reference documents are not published.

## Media

Add recovered company photos, videos, and partner logos to `assets/` and update the corresponding paths in the HTML. The original media files are not part of this repository yet.
